# Task 26: Equipamentos e Quilometragem de Tenis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir que atletas controlem tenis e rodagem por execucoes reais, com leitura segura pelo treinador.

**Architecture:** A migration cria tabelas tenant-first e RLS. Um servico calcula rodagem a partir de `execucoes_treino`; actions e componentes usam esse contrato sem recalcular no cliente.

**Tech Stack:** Next.js, React, TypeScript, Supabase Postgres/RLS, Zod, Vitest.

**Spec:** `docs/superpowers/specs/2026-08-29-task-26-tenis-design.md`

## Global Constraints

- Atleta altera somente os proprios equipamentos e vinculos.
- Treinador apenas le dados da propria assessoria.
- Uma execucao possui no maximo um tenis.
- Rodagem soma distancia real vinculada e quilometragem inicial.
- Avisos sao operacionais: 80% acompanhar, 100% limite atingido; nao sao recomendacao medica.
