# FLERNK

Plataforma SaaS de gestao para assessorias esportivas de corrida.

## Desenvolvimento

```bash
npm install
npm run dev
```

O aplicativo Next.js estara disponivel em `http://localhost:3000`.

## Comandos

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

O prototipo anterior foi preservado em `legacy/` durante a migracao.
